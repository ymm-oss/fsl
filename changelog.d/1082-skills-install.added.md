Added (#1082): `fslc` now carries the Agent Skills inside the binary, and `fslc skills install`, `fslc skills status`, and `fslc skills uninstall` place them, report drift, and take back exactly what they wrote. A project install copies into `.claude/skills`, chosen by a search bounded at the repository root so it cannot reach `~/.claude`. `--user` links the user-wide set through the same `current` payload `install.sh` builds. A hand-edited file is refused rather than overwritten, and a file no manifest records is left alone.
