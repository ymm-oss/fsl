Changed (#1818): The edition header reads `fsl MAJOR[.MINOR]`. `fsl 5.0` is read as `fsl 5` (and `fsl 4.0` as `fsl 4`); before, it was not a header and the document failed as an `fsl 4` one. A line that starts like a header but is not one (`fsl 5.`, `fsl 5.01`, `fsl 5.x`, `fsl 5 next`, `fsl 5 spec S {}`) is now `unsupported_edition` instead of a header-less document failing with `FSL-DIALECT-UNKNOWN` or an unexpected character; `fsl 5x` is unchanged. Any other minor is `unsupported_edition` (exit 2, message listing `4, 5`). Groundwork for the next minor of `fsl 5`, which is read only behind an unadvertised development gate and adds nothing yet; `--edition` values, `fsl_edition`, `migrate`'s default header and the verify cache key of every published run are unchanged.
