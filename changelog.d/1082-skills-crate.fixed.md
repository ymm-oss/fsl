Fixed (#1082): the embedded Agent Skills live in their own `fsl-skills` crate instead of the `fslc-rust` library. `fsl-wasm` and `fsl-lsp` link that library with default features off, so the skills module broke both builds outright -- it needs `sha2`, which `fslc-rust` declares optional under `native-cli`. `cargo build --workspace` passed throughout, because feature unification turns `native-cli` on for the binary; `tools/check-native-integration.sh` now checks the boundary in both directions, and `docs/DESIGN-rust-components.md` section 11 records the amended crate count.
