Fixed (#1481): In ordinary action/property contexts, BMC, induction, and explicit verification now agree with the Monitor's existing `partial_op` for reached `head()`, `at(i)`, and index reads of an empty zero-capacity Seq, instead of symbolic term-construction errors. Unreached reads that previously failed symbolic term construction now pass under short-circuit guards and disabled actions. Ordinary symbolic evaluation constructs a fresh, unconstrained read term outside the declared capacity for each otherwise unrepresentable read, without exposing its value in properties, witnesses, or traces or reusing agreement-only fallback values; temporaries with live elements retain their normal read semantics. Ranked `leadsTo` decreases measures are a narrow exception: a path-sensitive preflight refuses only reached zero-slot reads whose fresh value would otherwise enter rank evaluation, retaining the base semantics error (`head() on zero-capacity sequence` or `cannot select from an empty finite domain`). Unreached conditional and short-circuited measure reads can now prove by ranking where the base reported a semantics error. Physical-slot measures retain their existing behavior; capacity-zero push/pop and conditional-merge temporaries can still prove using stale/default physical-slot values on both base and head and remain #1542. This does not close the capacity-zero case or add general measure-definedness semantics; BMC's rank fast path discharges nothing on the preflight error.
