Fixed (#1082): `install.sh` no longer takes a skill link it did not create. It used to move anything at `~/.claude/skills/<name>` aside to `.pre-native-v3` and link its own payload in its place. `mise skills sync --global` writes that same directory, so a link mise placed was moved aside and left pointing at nothing mise knew about. Such a link is now reported and left alone. A link whose target no longer exists is still replaced, and a real directory is still backed up as before.
