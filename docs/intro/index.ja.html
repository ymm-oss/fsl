Formal Specification Language

FSLで、仕様を証拠として積み上げる

FSLは AI 時代の形式仕様言語です。書いた仕様そのものがドキュメントになり、人が読む説明とネイティブ Rust fslc が検証する対象が同じ1つのテキストです。

言語リファレンス · CLI · 概念

各証拠には限界があります。FSL はその限界を明示し、次の観測や反例で信頼を更新し続けることを前提にしています。権威ある検証器はネイティブ Rust の fslc（rust/fslc）です。src/fslc/ の凍結 Python パッケージは互換性参照のみです。
