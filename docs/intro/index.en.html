FSL is a formal specification language for the AI era. The spec you write is the documentation — the same text people read is what the native Rust fslc verifies.

Language reference · CLI · Concept

Each piece of evidence has limits. FSL makes those limits explicit so you can update confidence with the next observation or counterexample. The authoritative verifier is the native Rust fslc (rust/fslc); the frozen Python package under src/fslc/ is compatibility-only.
